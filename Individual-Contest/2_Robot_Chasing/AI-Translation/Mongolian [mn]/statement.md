# Роботын хөөцөлдөөн

- **Хугацааны хязгаар:** 5 минут
- **Орчин:** нэг GPU (≈16 GB VRAM), интернетгүй
- **Шийдлийн хэмжээ:** `solution.ipynb` ≤ 1 MB
- **Хадгалах зай:** 5 GB 

## Даалгавар

Зургаан робот байна. Робот бүр тороор дүрслэгдсэн жижиг өрөөнд ажиллана. Өрөө бүр ханаар хүрээлэгдсэн `6×6` тоглох талбайтай тул бүтэн `image` массивын хэмжээ `8×8` (тоглох талбай + хана) байна.

Робот бүр даалгаврыг тайлбарласан англи хэл дээрх заавар хүлээн авна. Робот даалгавраа гүйцэтгэж байх аль ч үед агшин зургийг авч болно. Таны зорилго бол роботын дараагийн үйлдлийг таамаглах явдал юм.

Роботууд үргэлж хамгийн богино замаар явдаггүй. Робот 0 нь Робот 1-ээс өөрөөр ажиллаж болох боловч робот бүр өөрийн тогтвортой хэв маягийг дагана. Зөв дараагийн үйлдлүүдийг агуулсан сургалтын жишээнүүдийг ашиглан эдгээр хэв маягийг сур.

![Робот](../../robot.jpg)

Гурван төрлийн даалгавар байна:

- объект руу **очих**, жишээлбэл `"approach the red ball"`;
- объектыг **авах**, жишээлбэл `"grab the blue key"`;
- **нэг объектыг нөгөө объектын хажууд тавих**, жишээлбэл
  `"place the red box beside the green ball"`.

Ижил зааврыг хэд хэдэн янзаар бичиж болно. Тестийн багц нь танил хэллэг, өнгө болон объектын төрлүүдийн шинэ хослолыг агуулж болно. Гэхдээ тестийн багцад ашигласан үг, хэллэгийн хэв маяг, өнгө, объектын төрөл болон даалгаврын төрөл бүр сургалтын багцад мөн гарна.

Жишээ бүр дараах талбаруудтай:

| Талбар | Утга |
|---|---|
| `robot_id` | энэ нь 6 роботын аль нь болох (`0`–`5`) |
| `image` | өрөө; `8×8×2` бүхэл тоон массив бөгөөд суваг 0 нь категорийн object_idx-ийг (жишээлбэл, 1=хоосон, 2=хана, 10=робот), суваг 1 нь категорийн colour_idx-ийг (0–5) агуулна. |
| `direction` | роботын одоо харж буй чиглэл |
| `mission` | харагдах байгалийн хэлний заавар |
| `carrying` | авч яваа объектын хувьд `null` эсвэл `[object_idx, colour_idx]` |

Мөрүүд нь санамсаргүй дараалалтай, бие даасан агшин зургууд юм. Тэд эпизод үүсгэхгүй бөгөөд үнэлгээний үед өмнөх ажиглалт эсвэл үйлдэл байхгүй.

Өгөгдсөн `visualize_dataset.ipynb` нь янз бүрийн нөхцөлд загварт боломжтой ажиглалтуудыг шалгах боломж олгоно.

## Торны кодчилол

`image[row][column] = [object_idx, colour_idx]`. Эхний индекс нь дээрээс доош чиглэсэн мөр, хоёр дахь индекс нь зүүнээс баруун чиглэсэн багана байна. Массив нь гаднах ханан хүрээг агуулдаг тул зорчих боломжтой дотор хэсэг нь `6×6` байна.

Объектын id-ууд:

| id | объект |
|---:|---|
| 1 | хоосон нүд |
| 2 | хана |
| 5 | түлхүүр |
| 6 | бөмбөг |
| 7 | хайрцаг |
| 10 | робот |
| 11 | token |

Өрөөнд token-ууд гарч болох боловч даалгаварт хэзээ ч нэрлэгддэггүй.

Өнгөний id-ууд нь `0` улаан, `1` ногоон, `2` цэнхэр, `3` нил ягаан, `4` шар, `5` саарал байна. Өнгөний суваг нь хоосон нүд болон хананы хувьд утгагүй.

Зураг нь зөвхөн дээрх хоёр сувагтай. Роботын чиглэлийг дээд түвшний `direction` талбарт нэг удаа өгнө; үүнийг `image` дотор давхардуулаагүй.

## Үйлдлүүд

`0`–`3` кодуудын хувьд хөдөлгөөний үйлдлүүд дараах абсолют харгалзаатай:

| үйлдэл | утга |
|---:|---|
| 0 | дээш хөдлөх |
| 1 | доош хөдлөх |
| 2 | зүүн тийш хөдлөх |
| 3 | баруун тийш хөдлөх |
| 4 | авах |
| 5 | тавих |


`direction` талбар нь одоогийн харж буй чиглэлийг дараах байдлаар заана: 0 = Дээш (row - 1), 1 = Доош (row + 1), 2 = Зүүн (col - 1), 3 = Баруун (col + 1).

Хөдөлгөөний үйлдэл нь эхлээд роботыг тухайн абсолют чиглэл рүү эргүүлээд, дараа нь нэг нүдээр хөдөлгөхийг оролдоно. Хана эсвэл объект хөдөлгөөнийг хааж болох боловч чиглэл ямар ч тохиолдолд өөрчлөгдөнө. `pick up` болон `drop` нь зөвхөн чиглэлээр тодорхойлогдсон зэргэлдээх зорилтот нүдэнд үйлчилнэ (жишээлбэл, direction=0 бол (row - 1, col) дээр үйлчилнэ).

## Өгөгдлийн багц

Танд хоёр хавтас өгнө:

| Хавтас | Мөр | `labels.json`? | Үүнийг ашиглах зорилго |
|---|---:|---|---|
| `dataset/train/` | 60,000 | багтсан | загвараа сургах |
| `dataset/test_public/` | 3,600 | хөгжүүлэлтийн хуулбарт багтсан | pipeline-аа ажиллуулж, өөрөө оноо тооцох |

Хавтас бүр дээр тайлбарласан жишээнүүдийн JSON жагсаалт болох `observations.json`-ийг
агуулна. `labels.json` нь үйлдлүүдийн (`0`–`5`) зэрэгцүүлсэн JSON жагсаалт юм.

Сургалтын багц нь робот бүрийн яг 10,000 мөр, даалгаврын бүлэг бүрийн 20,000 мөрийг агуулна. Нийтийн тест нь робот бүрийн 600 мөрийг агуулна. Хэрэв массив хэрэгтэй бол `image`-ийг
`numpy.asarray(...)`-ээр ороо.

Шалгах үед `dataset/test_public/` нь ижил форматтай боловч `labels.json`-гүй
3,600 ажиглалт бүхий нууц багцаар ил тод солигдоно. Нийтийн
онооны самбар `test_leaderboard_a`-ийг ашиглана; эцсийн эрэмбэ
`test_leaderboard_b`-ийг ашиглана. Тестийн шошгыг нөхцөлгүйгээр уншдаг notebook ажиллахгүй.
Шошгыг зөвхөн `dataset/train/`-оос унш.

## Гаралт

Notebook-ийн ажлын директорт `predictions.json`-ийг бич. Энэ нь
`dataset/test_public/observations.json`-ийн мөр бүрд ижил дарааллаар харгалзах нэг бүхэл тоон үйлдэл (`0`–`5`) агуулсан JSON
жагсаалт байх ёстой. Зургаан жишээ агуулсан таамаг тестийн багцын хувьд хүчинтэй гаралт нь:

```json
[0, 3, 2, 2, 5, 4]
```

JSON файл байхгүй эсвэл хүчингүй байх, таамаглалын тоо буруу байх, бүхэл тоо биш утга байх,
эсвэл `{0,1,2,3,4,5}`-ээс гадуурх үйлдэл байх тохиолдолд оноо өгөхгүйгээр татгалзана.

## Оноолт

Оноолт нь `0`–`100` хуваарь дээрх **робот тус бүрийн нарийвчлалын дундаж** байна. Нарийвчлалыг эхлээд
робот бүрийн хувьд тусад нь тооцоод, дараа нь бүх зургаан роботын дунджаар авна. Иймээс
робот бүр ижил жинтэй байна.

## Хэрхэн илгээх вэ

1. `solution.ipynb`-ийг нээж, бүх нүдийг ажиллуул.
2. Энэ нь нийтийн тестийн багцад зориулсан 3,600 таамаглал бүхий `predictions.json`-ийг бичиж байгааг
   баталгаажуул.
3. Хэрэв хүсвэл загварыг сайжруул; өгөгдсөн суурь загвар нь зөвхөн
   шаардлагатай оролт болон гаралтын форматыг харуулна.
4. JupyterLab Git таб дээр `solution.ipynb`-ийг stage хийж commit хийгээд, дараа нь push хий.
5. Тэмцээний хуудас руу буцаж очоод **Илгээх** дээр дар.

`solution.ipynb` нэртэй яг нэг файл илгээ.
