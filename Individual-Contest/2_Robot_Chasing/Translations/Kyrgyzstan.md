# Robot Chasing

- **Убакыт чеги:** 5 мүнөт
- **Чөйрө:** бир GPU (≈16 GB VRAM), интернетсиз
- **Чечимдин өлчөмү:** `solution.ipynb` ≤ 1 MB
- **Сактагыч:** 5 GB 

## Тапшырма

Алты робот бар. Ар бир робот торчо түрүндө көрсөтүлгөн чакан бөлмөдө иштейт. Ар бир бөлмө дубалдар менен курчалган `6×6` оюн талаасына ээ, ошондуктан толук `image` массивинин өлчөмү `8×8` түзөт (оюн талаасы + дубалдар).

Ар бир робот тапшырманы сүрөттөгөн англис тилиндеги нускама алат. Кадр (snapshot) робот тапшырманы аткарып жаткан каалаган учурда тартылышы мүмкүн. Сиздин максатыңыз — роботтун кийинки аракетин болжолдоо.

Роботтор дайыма эле эң кыска жол менен барышпайт. 0-робот 1-роботтон башкача аракеттениши мүмкүн, бирок ар бир робот өзүнүн туруктуу үлгүсүнө (pattern) баш ийет. Бул үлгүлөрдү үйрөнүү үчүн туура кийинки аракеттерди камтыган окутуу үлгүлөрүн (training examples) колдонуңуз.

![Robot](../robot.jpg)

Миссиялардын үч түрү бар:

- объектке **баруу** (go to), мисалы `"approach the red ball"`;
- объектти **көтөрүү** (pick up), мисалы `"grab the blue key"`;
- **бир объектти экинчисинин жанына коюу** (put one object next to another), мисалы
  `"place the red box beside the green ball"`.

Бир эле нускама бир нече жол менен жазылышы мүмкүн. Тесттик топтомдо тааныш фразалардын, түстөрдүн жана объект түрлөрүнүн жаңы комбинациялары камтылышы мүмкүн. Бирок, тесттик топтомдо колдонулган ар бир сөз, фраза үлгүсү, түс, объект түрү жана миссия түрү окутуу топтомунда да бар.

Ар бир үлгү төмөнкү талааларга ээ:

| Талаа | Мааниси |
|---|---|
| `robot_id` | бул 6 роботтун кайсынысы экени (`0`–`5`) |
| `image` | бөлмө, 0-каналы категориялык object_idx (мисалы, 1=бош, 2=дубал, 10=робот) жана 1-каналы категориялык colour_idx (0–5) камтыган `8×8×2` бүтүн сандар массиви. |
| `direction` | робот учурда карап турган багыт |
| `mission` | көрүнүүчү табигый тилдеги нускама |
| `carrying` | көтөрүлүп жаткан объект үчүн `null` же `[object_idx, colour_idx]` |

Саптар кокустук тартиптеги көз карандысыз кадрлар болуп саналат. Алар эпизоддорду түзбөйт жана баалоо учурунда мурунку байкоолор же аракеттер жеткиликтүү болбойт.

Берилген `visualize_dataset.ipynb` ар кандай кырдаалдарда модель үчүн жеткиликтүү болгон байкоолорду карап чыгууга мүмкүндүк берет.

## Торчону коддоо

`image[row][column] = [object_idx, colour_idx]`. Биринчи индекс — жогорудан ылдыйды көздөй сап, ал эми экинчиси — солдон оңду көздөй тилке. Массив тышкы дубал чек арасын камтыйт, ошондуктан өтүүгө мүмкүн болгон ички бөлүк `6×6` түзөт.

Объект IDлери:

| id | объект |
|---:|---|
| 1 | бош уяча |
| 2 | дубал |
| 5 | ачкыч |
| 6 | топ |
| 7 | куту |
| 10 | робот |
| 11 | токен |

Токендер бөлмөдө пайда болушу мүмкүн, бирок миссияларда эч качан аталбайт.

Түс IDлери: `0` кызыл, `1` жашыл, `2` көк, `3` сыя түш, `4` сары жана `5` боз. Түс каналы бош уячалар жана дубалдар үчүн эч кандай мааниге ээ эмес.

Сүрөттө жогорудагы эки гана канал бар. Роботтун багыты жогорку деңгээлдеги `direction` талаасында бир жолу берилет; ал `image` ичинде кайталанбайт.

## Аракеттер

`0`–`3` коддору үчүн кыймыл аракеттери төмөнкү абсолюттук чагылдырууну колдонот:

| аракет | мааниси |
|---:|---|
| 0 | өйдө жылуу |
| 1 | ылдый жылуу |
| 2 | солго жылуу |
| 3 | оңго жылуу |
| 4 | көтөрүү |
| 5 | таштоо |


`direction` талаасы учурдагы багытты төмөнкүдөй көрсөтөт: 0 = Өйдө (row - 1), 1 = Ылдый (row + 1), 2 = Сол (col - 1), 3 = Оң (col + 1).

Кыймыл аракети адегенде роботту ошол абсолюттук багытка бурат, андан кийин аны бир уячага жылдырууга аракет кылат. Дубал же объект кыймылды бөгөттөшү мүмкүн, бирок багыты баары бир өзгөрөт. `pick up` жана `drop` багыт менен аныкталган жана чектеш болгон максаттуу уячага гана таасир этет (мисалы, эгер direction=0 болсо, ал (row - 1, col) уячасына таасир этет).

## Маалымат топтому

Сизге эки папка берилет:

| Папка | Саптар | `labels.json`? | Төмөнкү үчүн колдонуңуз |
|---|---:|---|---|
| `dataset/train/` | 60,000 | камтылган | моделиңизди окутуу үчүн |
| `dataset/test_public/` | 3,600 | иштеп чыгуу көчүрмөсүндө камтылган | пайплайныңызды иштетүү жана өзүңүз баалоо үчүн |

Ар бир папка жогоруда сүрөттөлгөн үлгүлөрдүн JSON тизмеси болгон `observations.json` файлын камтыйт. `labels.json` — аракеттердин (`0`–`5`) дал келтирилген JSON тизмеси.

Окутуу топтому ар бир робот үчүн так 10,000 сапты жана ар бир тапшырма үй-бүлөсүнөн 20,000 сапты камтыйт. Ачык тесттик топтом ар бир робот үчүн 600 сапты камтыйт. Эгер сизге массив керек болсо, `image` файлын `numpy.asarray(...)` менен ороп алыңыз.

Баалоо учурунда `dataset/test_public/` дал ушундай форматтагы, бирок `labels.json` ажыратылган 3,600 жашыруун байкоо топтому менен ачык-айкын алмаштырылат. Ачык лидерборд `test_leaderboard_a` колдонот; акыркы рейтинг `test_leaderboard_b` колдонот. Тесттик энбелгилерди шартсыз окуган ноутбук иштебей калат. Энбелгилерди `dataset/train/` ичинен гана окуңуз.

## Чыгаруу

Ноутбуктун жумушчу каталогунда `predictions.json` жазыңыз. Ал `dataset/test_public/observations.json` файлынын ар бир сабы үчүн ошол эле тартипте бирден бүтүн сандуу аракетти (`0`–`5`) камтыган JSON тизмеси болушу керек. Алты үлгүдөн турган гипотетикалык тесттик топтом үчүн жарактуу чыгуучу маалымат төмөнкүчө болот:

```json
[0, 3, 2, 2, 5, 4]
```

Иштебеген же кабыл алынбаган JSON файлы, туура эмес сандагы болжолдоолор, бүтүн эмес маани же `{0,1,2,3,4,5}` диапазонунан тышкаркы аракет упайсыз четке кагылат.

## Баалоо

Баалоо — `0`–`100` шкаласындагы **робот боюнча орточо тактык**. Тактык алгач ар бир робот үчүн өзүнчө эсептелинет, андан кийин бардык алты робот боюнча орточо мааниси алынат. Демек, ар бир робот бирдей салмакка ээ.

## Кантип тапшыруу керек

1. `solution.ipynb` ачыңыз жана бардык уячаларды иштетиңиз.
2. Ал ачык тесттик топтом үчүн 3,600 болжолдоо менен `predictions.json` файлын жазганын ырастаңыз.
3. Кааласаңыз, моделди жакшыртыңыз; берилген бейзлайн (baseline) талап кылынган кириш жана чыгыш форматын гана көрсөтөт.
4. JupyterLab Git өтмөгүндө `solution.ipynb` файлын индексациялаңыз (stage) жана коммиттеңиз (commit), андан кийин push кылыңыз.
5. Конкурс баракчасына кайтып келип, **Submit** баскычын басыңыз.

`solution.ipynb` деп аталган так бир файлды тапшырыңыз.
