# Роботты қуу

- **Уақыт шектеуі:** 5 минут
- **Орта:** бір GPU (≈16 GB VRAM), интернет жоқ
- **Шешім көлемі:** `solution.ipynb` ≤ 1 MB
- **Сақтау орны:** 5 GB 

## Тапсырма

Алты робот бар. Әр робот тор түрінде көрсетілген шағын бөлмеде әрекет етеді. Әр бөлменің қабырғалармен қоршалған `6×6` әрекет етуге болатын аумағы бар, сондықтан толық `image` массивінің өлшемі `8×8` (әрекет етуге болатын аумақ + қабырғалар).

Әр роботқа тапсырманы сипаттайтын ағылшын тіліндегі нұсқау беріледі. Кез келген сәтте робот оны орындап жатқанының кескіні түсірілуі мүмкін. Сіздің мақсатыңыз — роботтың келесі әрекетін болжау.

Роботтар әрдайым ең қысқа жолмен жүрмейді. 0-робот 1-роботтан өзгеше әрекет етуі мүмкін, бірақ әр робот өзінің тұрақты ережелерді  ұстанады. Осы ережелерді үйрену үшін дұрыс келесі әрекеттері берілген оқыту мысалдарын пайдаланыңыз.

![Робот](../robot.jpg)

Миссиялардың үш түрі бар:

- объектіге **бару**, мысалы `"approach the red ball"`;
- объектіні **көтеріп алу**, мысалы `"grab the blue key"`;
- **бір объектіні екіншісінің жанына қою**, мысалы
  `"place the red box beside the green ball"`.

Бір нұсқау бірнеше түрде жазылуы мүмкін. Тест жиынында таныс тіркестердің, түстердің және объект түрлерінің жаңа комбинациялары болуы мүмкін. Алайда тест жиынында қолданылатын әрбір сөз, сөзді тіркес үлгісі, түс, объект түрі және миссия түрі оқыту жиынында(training set) да кездеседі.

Әр үлгіде келесі өрістер бар:

| Өріс | Мағынасы |
|---|---|
| `robot_id` | бұл 6 роботтың қайсысы екені (`0`–`5`) |
| `image` | бөлме, `8×8×2` бүтін сандар массиві, мұнда 0-арнада категориялық object_idx (мысалы, 1=бос, 2=қабырға, 10=робот), ал 1-арнада категориялық colour_idx (0–5) сақталады. |
| `direction` | роботтың қазіргі қарап тұрған бағыты |
| `mission` | көрінетін табиғи тілдегі нұсқау |
| `carrying` | тасымалданатын объект үшін `null` немесе `[object_idx, colour_idx]` |

Жолдар — кездейсоқ ретпен берілген тәуелсіз суреттер. Олар эпизодтарды құрамайды және бағалау кезінде алдыңғы бақылау немесе әрекет қолжетімді болмайды.

Берілген `visualize_dataset.ipynb` әртүрлі жағдайларда модельге қолжетімді бақылауларды тексеруге мүмкіндік береді.

## Тордың кодталуы

`image[row][column] = [object_idx, colour_idx]`. Бірінші индекс — жоғарыдан төмен қарайғы қатар, ал екінші индекс — солдан оңға қарайғы баған. Массив сыртқы қабырға жиегін қамтиды, сондықтан жүріп өтуге болатын ішкі бөлік `6×6`.

Объект id-лері:

| id | объект |
|---:|---|
| 1 | бос ұяшық |
| 2 | қабырға |
| 5 | кілт |
| 6 | доп |
| 7 | қорап |
| 10 | робот |
| 11 | token |

Token-дер бөлмеде кездесуі мүмкін, бірақ миссияларда ешқашан аталмайды.

Түс id-лері: `0` қызыл, `1` жасыл, `2` көк, `3` күлгін, `4` сары және `5` сұр. Бос ұяшықтар мен қабырғалар үшін түс арнасының мағынасы жоқ.

Кескінде тек жоғарыдағы екі арна бар. Роботтың бағыты жоғарғы деңгейдегі `direction` өрісінде бір рет беріледі; ол `image` ішінде қайталанбайды.

## Әрекеттер

`0`–`3` кодтары үшін қозғалыс әрекеттері келесі абсолютті сәйкестікті қолданады:

| әрекет | мағынасы |
|---:|---|
| 0 | жоғары жылжу |
| 1 | төмен жылжу |
| 2 | солға жылжу |
| 3 | оңға жылжу |
| 4 | көтеріп алу |
| 5 | тастау |


`direction` өрісі қазіргі қарау бағытын былай көрсетеді: 0 = Жоғары (row - 1), 1 = Төмен (row + 1), 2 = Солға (col - 1), 3 = Оңға (col + 1).

Қозғалыс әрекеті алдымен роботты сол абсолютті бағыт жаққа бұрады, содан кейін оны бір ұяшыққа жылжытуға әрекет жасайды. Қабырға немесе объект қозғалысты бөгеуі мүмкін, бірақ бағыт бәрібір өзгереді. `pick up` және `drop` тек бағытпен анықталған іргелес нысана ұяшығына әсер етеді (мысалы, direction=0 болса, ол (row - 1, col) ұяшығына әсер етеді).

## Датасет

Сізге екі бума беріледі:

| Бума | Жолдар | `labels.json`? | Оны не үшін пайдалану керек |
|---|---:|---|---|
| `dataset/train/` | 60,000 | қамтылған | модельді оқыту |
| `dataset/test_public/` | 3,600 | әзірлеу көшірмесінде қамтылған | кодты тексеру және өз-өзіңді бағалау |

Әр бумада жоғарыда сипатталған үлгілердің JSON тізімі — `observations.json` бар.
`labels.json` — сәйкестендірілген JSON әрекеттердің тізімі (`0`–`5`).

Оқыту жиынында әр робот үшін дәл 10,000 жол және әр тапсырма тобы үшін 20,000 жол бар. Ашық тестте әр робот үшін 600 жол бар. Егер массив қажет болса, `image` мәнін
`numpy.asarray(...)` көмегімен ораңыз.

Бағалау кезінде `dataset/test_public/` дәл сол форматтағы, бірақ `labels.json` жоқ
3,600 бақылаудан тұратын жасырын жиынмен автоматты түрде ауыстырылады. Ашық
лидерлер кестесі `test_leaderboard_a` қолданады; қорытынды рейтинг
`test_leaderboard_b` қолданады. Тест белгілерін сөзсіз оқитын notebook сәтсіз аяқталады.
Белгілерді тек `dataset/train/` ішінен оқыңыз.

## Шығыс

Notebook-тың жұмыс бумасына `predictions.json` жазыңыз. Ол
`dataset/test_public/observations.json` жиынының әр жолына дәл сол ретпен бір бүтін әрекеттен (`0`–`5`) тұратын JSON
тізімі болуы керек. Алты үлгіден тұратын гипотетикалық тест жиыны үшін жарамды шығыс мынадай болар еді:

```json
[0, 3, 2, 2, 5, 4]
```

Жоқ немесе жарамсыз JSON файлы, болжамдар санының дұрыс болмауы, бүтін сан емес мән
немесе `{0,1,2,3,4,5}` ауқымынан тыс әрекет ұпай берілместен қабылданбайды.

## Бағалау

Бағалау көрсеткіші — `0`–`100` шкаласындағы **әр робот бойынша орташа дәлдік**. Алдымен дәлдік
әр робот үшін тәуелсіз есептеледі, содан кейін барлық алты робот бойынша орташаланады. Сондықтан әр
роботтың салмағы бірдей.
