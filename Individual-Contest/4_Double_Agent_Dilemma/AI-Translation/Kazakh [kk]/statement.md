# Қос агент дилеммасы

- **Уақыт шектеуі:** 12 минут.
- **Жад көлемі:** 5 GB
- **Орта:** бір GPU (≈16 GB VRAM), интернет жоқ
- **Шешім өлшемі:** `solution.ipynb` ≤ 1 MB
- **Baseline ұпайы:** 0 
- **Ғылыми комитеттің ұпайы:** 96.99 

Астанадағы ұлттық ЖИ орталығында екі компьютерлік модель — Model R (ResNet-18) және Model V (ViT-Tiny) — фотосуреттерді талдап отыр. Дәл қазір екі модель де мінсіз жұмыс істеп, 100% дәлдік көрсетіп, әрбір суретте бір-бірімен келісіп отыр. Олардың «сана-миының» шын мәнінде қаншалықты өзгеше екенін тексеру үшін бас ғалым сізге сынақ қояды: әрбір фотосуретке ұсақ, көзге көрінбейтіндей пиксель өзгерістерін енгізіп, Model R мен Model V толықтай келіспейтіндей етіңіз.

## 1. Тапсырма

Алдын ала оқытылған екі сурет классификаторы бір суретке қарайды. Осы тапсырмада берілген суреттерде екі классификатор да 100% дәлдікпен жұмыс істейді.

- **Model R**: `torchvision.models.resnet18` (CNN, ResNet18).
- **Model V**: `timm`'s `vit_tiny_patch16_224` (Transformer, ViT-Tiny).

Сіздің міндетіңіз — әрбір сурет үшін екі модель келіспейтіндей шағын өзгеріс («перturbация», perturbation) жасау. Әрбір сурет үшін **екі түрлі** перturbация жасауыңыз керек:

- **A түрі**: оны қосқаннан кейін Model R суретті әлі де дұрыс жіктейді, ал Model V қате жіктейді.
- **B түрі**: оны қосқаннан кейін Model V суретті әлі де дұрыс жіктейді, ал Model R қате жіктейді.

Әрбір перturbация байқау қиын болатындай *шағын* болуы керек. Кішірек перturbациялар жоғары ұпай алады (5-бөлімді қараңыз). Перturbация түпнұсқа суретке тікелей пиксель деңгейінде қолданылады.

## 2. Ашық деректер

Тапсырмамен бірге суреттер жиынтығы беріледі, ол екі бөлікке ұйымдастырылған — `train` (100 сурет) және
`test_public` (100 сурет) — әрқайсысында ажыратымдылығы әртүрлі суреттер бар. Барлық суреттер ImageNet-1K-нің 1000 класынан алынған және Model R да, Model V да екі бөлікте де 100% дәлдікке жетеді.

Келесі файлдар беріледі:

```text
train/images/*.png         # 100 images in PNG format
train/labels.json          # maps each image index to its correct class
test_public/images/*.png   # 100 images in PNG format
test_public/labels.json    # maps each image index to its correct class
```

Бағалау кезінде сіздің `dataset/test_public/` қалтаңыз ресми ұпай есептеу үшін екі жасырын сурет жиынтығымен (`test_leaderboard_a` және `test_leaderboard_b`) айқын түрде ауыстырылады. Олардың әрқайсысында PNG форматындағы **100 сурет** және таңбалар файлы бар. 

**Ескерту: Бұл тапсырмада тест деректер жиынтықтарындағы таңбалар қолжетімді.**

## 3. Шығыс форматы

Әрбір сурет үшін екі файл жасауыңыз керек:

```text
{index}_a.pt   # Type A perturbation
{index}_b.pt   # Type B perturbation
```

- `{index}` (`0`, `1`, `2`, ...) деректер жиынтықтарындағы суреттің атауына сәйкес келеді.
- Әрбір файл — `torch.save` арқылы сақталған жалғыз тензор. Оның пішіні`3 x H x W` болуы керек, мұндағы `H` және `W` сол суреттің **түпнұсқа** ажыратымдылығына сәйкес келеді (`224 x 224` емес).
- Код тек бір ZIP файл — `submission.zip` — жасауы керек. Барлық `.pt` файлдарын ZIP архивінің жоғарғы деңгейіне, ешқандай сыртқы қалта немесе ішкі каталогтарсыз орналастырыңыз. 

```text
submission.zip
├── 0_a.pt
├── 0_b.pt
└── 1_a.pt
└── ...
```

Шығыс форматында қандай да бір мәселе болса, ноутбук сізге ескерту береді.

## 4. Шектеулер

- **Модельдер:** Сіз `torchvision.models.resnet18(pretrained=True)` және `timm.create_model('vit_tiny_patch16_224', pretrained=True)` пайдалануыңыз керек. Басқа алдын ала оқытылған модельдерге жол берілмейді.
- **Түрлендіру конвейері (бағалау кезінде мәжбүрлі қолданылады):** `Resize(256) → CenterCrop(224) →
  Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])`. See Section 3 of `baseline.ipynb` файлын толық ақпарат үшін қараңыз. 
- **Перturbация ажыратымдылығы:** **Түпнұсқа** өңделмеген сурет ажыратымдылығына сәйкес келуі керек (224×224 емес). Тензор өңделмеген суретке түрлендіру конвейеріне *дейін* қосылады.
- **Шығыс форматы:** Тек `.pt` файлдары — PNG/JPG емес. Тензорлар өңделмеген суретке қосылады және пиксель мәндері алдын ала өңдеуден бұрын `[0, 1]` аралығына қысылады (clip).
- **Файл атауы:** Жалпақ тізім, қатаң `{index}_a.pt` / `{index}_b.pt` форматы. Zip ішінде ішкі каталогтар болмауы керек.
- **Кітапханалар:** `torch`, `torchvision`, `timm`. 

## 5. Ұпай есептеу

Қорытынды ұпай келесідей есептеледі. `M` — бөліктегі суреттер саны, $Score_A$ — сәтті A түріндегі перturbациялар саны, $Score_B$ — сәтті B түріндегі перturbациялар саны болсын:
$$
S_{final} = \frac{Score_A + Score_B}{2M} \times PF
$$

PF — нормасы жоғары перturbацияларды жазалауға және өнімділік шегіне жақын жерде өте сезімтал болуға арналған функция. Ол 0.5-тен 1-ге дейінгі аралықпен шектелген. Толық іске асырылуын `solution.ipynb` файлының 8-бөлімінде көруге болады.
