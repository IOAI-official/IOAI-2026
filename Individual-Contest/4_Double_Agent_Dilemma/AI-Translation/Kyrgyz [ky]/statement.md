# Кош агент дилеммасы

- **Убакыт чектөөсү:** 12 мүнөт.
- **Эс тутум:** 5 ГБ
- **Чөйрө:** бир GPU (≈16 ГБ VRAM), интернетсиз
- **Чечимдин өлчөмү:** `solution.ipynb` ≤ 1 МБ
- **Базалык упай:** 0 
- **Илимий комитеттин упайы:** 96.99 

Астанадагы улуттук Жасалма интеллект борборунда эки компьютердик модель — Модель R (ResNet-18) жана Модель V (ViT-Tiny) — сүрөттөрдү анализдеп жатышат. Учурда эки модель тең 100% тактык көргөзүп, ар бир сүрөт боюнча бирдей чечим чыгарып, эң сонун иштеп жатышат. Алардын акылдуу "мээлери" канчалык айырмаланарын текшерүү үчүн, башкы окумуштуу сизге тапшырма берет: Модель R жана Модель V таптакыр карама-каршы чечим чыгарышы үчүн, ар бир сүрөткө кичинекей, дээрлик байкалбаган пикселдик өзгөртүүлөрдү киргизиңиз.

## 1. Тапшырма

Алдын ала үйрөтүлгөн сүрөттөрдүн эки классификатору бир эле сүрөттү карашат. Бул тапшырмада берилген сүрөттөрдө эки классификатор тең 100% тактык менен иштешет.

- **Модель R**: `torchvision.models.resnet18` (CNN, ResNet18).
- **Модель V**: `timm` компаниясынын `vit_tiny_patch16_224` модели (Transformer, ViT-Tiny).

Сиздин тапшырмаңыз — эки модель бир чечимге келбей калышы үчүн ар бир сүрөт үчүн чакан өзгөртүү ("пертурбация") түзүү. Ар бир сүрөт үчүн сиз **эки ар башка** пертурбация түзүшүңүз керек:

- **Type A**: аны кошкондон кийин Модель R сүрөттү дагы эле туура классификациялайт, ал эми Модель V туура эмес классификациялайт.
- **Type B**: аны кошкондон кийин Модель V сүрөттү дагы эле туура классификациялайт, ал эми Модель R туура эмес классификациялайт.

Ар бир пертурбация байкоого кыйын боло тургандай *кичинекей* болушу керек. Кичине пертурбациялар жогорураак упай алат (5-бөлүмдү караңыз). Пертурбация түздөн-түз пикселдик деңгээлде баштапкы сүрөткө колдонулат.

## 2. Ачык маалыматтар

Тапшырма менен бирге сүрөттөрдүн топтому берилет, алар эки бөлүккө (split) иреттелген — `train` (100 сүрөт) жана `test_public` (100 сүрөт) — алардын ар биринде ар кандай уруксаттагы (resolution) сүрөттөр бар. Бардык сүрөттөр ImageNet-1K'тин 1000 классынан алынган жана Модель R да, Модель V да эки бөлүктө тең 100% тактыкка жетишет.

Төмөнкү файлдар берилген:

```text
train/images/*.png         # 100 images in PNG format
train/labels.json          # maps each image index to its correct class
test_public/images/*.png   # 100 images in PNG format
test_public/labels.json    # maps each image index to its correct class
```

Баалоо учурунда расмий упайларды эсептөө үчүн сиздин `dataset/test_public/` папкаңыз сүрөттөрдүн эки жашыруун топтомуна (`test_leaderboard_a` жана `test_leaderboard_b`) ачык-айкын алмаштырылат. Алардын ар биринде PNG форматындагы **100 сүрөт** жана энбелгилер файлы камтылган. 

**Эскертүү: Бул тапшырма үчүн тесттик маалыматтар топтомундагы энбелгилерге ачык кирүүгө болот.**

## 3. Чыгуу форматы

Ар бир сүрөт үчүн сиз эки файл даярдашыңыз керек:

```text
{index}_a.pt   # Type A perturbation
{index}_b.pt   # Type B perturbation
```

- `{index}` (`0`, `1`, `2`, ...), маалымат топтомдорундагы сүрөттүн аталышына дал келет.
- Ар бир файл `torch.save` менен сакталган бир тензор болуп саналат. Анын формасы `3 x H x W` болушу керек, мында `H` жана `W` ошол сүрөттүн **баштапкы** уруксатына дал келет (`224 x 224` эмес).
- Код бир гана ZIP файлын, `submission.zip` файлын чыгарышы керек. Бардык `.pt` файлдарын ZIP архивдин эң жогорку деңгээлине жайгаштырыңыз, ичине эч кандай папка же поддиректория кошпоңуз. 

```text
submission.zip
├── 0_a.pt
├── 0_b.pt
└── 1_a.pt
└── ...
```

Эгер чыгуу форматында кандайдыр бир көйгөйлөр болсо, ноутбук сизге эскертет.

## 4. Чектөөлөр

- **Моделдер:** Сиз `torchvision.models.resnet18(pretrained=True)` жана `timm.create_model('vit_tiny_patch16_224', pretrained=True)` моделдерин колдонушуңуз керек. Башка алдын ала үйрөтүлгөн моделдерди колдонууга уруксат берилбейт.
- **Трансформация пайплайны (баалоодо колдонулат):** `Resize(256) → CenterCrop(224) →
  Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])`. See Section 3 of `baseline.ipynb` деталдар үчүн караңыз. 
- **Пертурбациянын уруксаты:** Баштапкы иштетилбеген сүрөттүн **баштапкы** уруксатына дал келиши керек (224×224 эмес). Тензор трансформация пайплайнына чейин *иштетилбеген сүрөткө* кошулат.
- **Чыгуу форматы:** Бир гана `.pt` файлдары — PNG/JPG эмес. Тензорлор иштетилбеген сүрөткө кошулат жана пикселдик маанилер алдын ала иштетүүдөн мурда `[0, 1]` диапазонуна чектелип кыркылат.
- **Файлдарды атоолор:** Жөнөкөй тизмеленген, катуу `{index}_a.pt` / `{index}_b.pt` форматы. Zip ичинде поддиректориялар болбошу керек.
- **Китепканалар:** `torch`, `torchvision`, `timm`. 

## 5. Баалоо

Жыйынтыктоочу упай төмөнкүчө эсептелет. `M` бөлүктөгү сүрөттөрдүн саны, $Score_A$ ийгиликтүү жасалган Type A пертурбацияларынын саны, ал эми $Score_B$ ийгиликтүү жасалган Type B пертурбацияларынын саны болсун:
$$
S_{final} = \frac{Score_A + Score_B}{2M} \times PF
$$

PF — чоң нормага ээ болгон пертурбацияларга айып упайын салуу жана өндүрүмдүүлүктүн жогорку чегине жакын жерде абдан сезгич болуу үчүн иштелип чыккан функция. Анын мааниси 0.5тен 1ге чейинки диапазондо чектелген. Толук ишке ашырууну `solution.ipynb` файлынын 8-бөлүмүнөн көрүүгө болот.
