# Давхар агентын дилемма

- **Хугацааны хязгаар:** 12 минут.
- **Хадгалах зай:** 5 GB
- **Орчин:** нэг GPU (≈16 GB VRAM), интернэтгүй
- **Шийдлийн хэмжээ:** `solution.ipynb` ≤ 1 MB
- **Суурь загварын оноо:** 0 
- **Шинжлэх ухааны хорооны оноо:** 96.99 

Астана дахь үндэсний хиймэл оюуны төвд Model R (ResNet-18) болон Model V (ViT-Tiny) гэсэн хоёр компьютерын загвар гэрэл зургуудыг шинжилж байна. Одоогоор хоёр загвар хоёулаа ажлаа төгс гүйцэтгэж, 100% нарийвчлалтай бөгөөд зураг бүр дээр ижил хариу өгч байна. Тэдний ухаалаг “тархи” үнэндээ хэр ялгаатайг шалгахын тулд ахлах эрдэмтэн танд дараах сорилтыг өгнө: гэрэл зураг бүрийн пикселүүдэд өчүүхэн, бараг үл харагдах өөрчлөлт хийж, Model R болон Model V-ийн хариуг бүрэн зөрүүлэх.

## 1. Даалгавар

Урьдчилан сургасан хоёр зураг ангилагч ижил зургийг шинжилнэ. Энэ даалгаварт өгсөн зургууд дээр хоёр ангилагч хоёулаа 100% нарийвчлалтай ажиллана.

- **Model R**: `torchvision.models.resnet18` (CNN, ResNet18).
- **Model V**: `timm`-ийн `vit_tiny_patch16_224` (Transformer, ViT-Tiny).

Таны даалгавар бол зураг бүрд жижиг өөрчлөлт (“пертурбаци”) үүсгэж, хоёр загварын хариуг зөрүүлэх явдал юм. Зураг бүрд та **хоёр өөр** пертурбаци үүсгэх ёстой:

- **A төрөл**: үүнийг нэмсний дараа Model R зургийг зөв ангилсан хэвээр байх боловч Model V буруу ангилна.
- **B төрөл**: үүнийг нэмсний дараа Model V зургийг зөв ангилсан хэвээр байх боловч Model R буруу ангилна.

Пертурбаци бүр анзаарахад хэцүү байхаар хангалттай *жижиг* байх ёстой. Жижиг пертурбаци илүү өндөр оноо авна (5-р хэсгийг үзнэ үү). Пертурбацийг эх зурагт пикселийн түвшинд шууд хэрэглэнэ.

## 2. Нийтийн өгөгдөл

Даалгаврын хамт янз бүрийн нягтралтай зургуудаас бүрдэх `train` (100 зураг) болон
`test_public` (100 зураг) гэсэн хоёр хуваалтад зохион байгуулсан зургийн багц өгөгдөнө. Бүх зураг ImageNet-1K-ийн 1000 ангиас авсан бөгөөд Model R болон Model V хоёулаа хоёр хуваалт дээр 100% нарийвчлалтай ажиллана.

Дараах файлууд өгөгдөнө:

```text
train/images/*.png         # 100 images in PNG format
train/labels.json          # maps each image index to its correct class
test_public/images/*.png   # 100 images in PNG format
test_public/labels.json    # maps each image index to its correct class
```

Үнэлгээний үеэр таны `dataset/test_public/` хавтсыг албан ёсны оноолтод зориулсан хоёр нууц зургийн багцаар (`test_leaderboard_a` болон `test_leaderboard_b`) автоматаар орлуулна. Тэдгээр нь тус бүр PNG форматтай **100 зураг** болон шошгын файл агуулна. 

**Тэмдэглэл: Энэ даалгаврын хувьд тестийн өгөгдлийн багцуудын шошгыг харах боломжтой.**

## 3. Гаралтын формат

Зураг бүрд та хоёр файл үүсгэх ёстой:

```text
{index}_a.pt   # Type A perturbation
{index}_b.pt   # Type B perturbation
```

- `{index}` (`0`, `1`, `2`, ...), нь өгөгдлийн багц дахь зургийн нэртэй таарна.
- Файл бүр `torch.save` ашиглан хадгалсан нэг тензор байна. Түүний хэлбэр`3 x H x W` байх ёстой бөгөөд `H` болон `W` нь тухайн зургийн **эх** нягтралтай (`224 x 224` биш) таарна.
- Код нь зөвхөн `submission.zip` нэртэй нэг ZIP файл үүсгэх ёстой. Бүх `.pt` файлыг ямар ч агуулах хавтас эсвэл дэд хавтасгүйгээр ZIP архивын дээд түвшинд байрлуулна. 

```text
submission.zip
├── 0_a.pt
├── 0_b.pt
└── 1_a.pt
└── ...
```

Гаралтын форматад ямар нэг асуудал байвал notebook танд анхааруулна.

## 4. Хязгаарлалтууд

- **Загварууд:** Та `torchvision.models.resnet18(pretrained=True)` болон `timm.create_model('vit_tiny_patch16_224', pretrained=True)`-ийг ашиглах ёстой. Урьдчилан сургасан өөр загвар ашиглахыг зөвшөөрөхгүй.
- **Хувиргалтын дамжлага (үнэлгээний үед мөрдүүлнэ):** `Resize(256) → CenterCrop(224) →
  Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])`. See Section 3 of `baseline.ipynb`-ээс дэлгэрэнгүйг үзнэ үү. 
- **Пертурбацийн нягтрал:** **Эх** боловсруулаагүй зургийн нягтралтай (224×224 биш) таарах ёстой. Тензорыг хувиргалтын дамжлагаас *өмнө* боловсруулаагүй зурагт нэмнэ.
- **Гаралтын формат:** Зөвхөн `.pt` файлууд — PNG/JPG биш . Тензоруудыг боловсруулаагүй зурагт нэмэх бөгөөд урьдчилсан боловсруулалтын өмнө пикселийн утгуудыг `[0, 1]` мужид тасална.
- **Файлын нэршил:** Нэг түвшинд жагсаасан, `{index}_a.pt` / `{index}_b.pt` гэсэн хатуу форматтай байна. ZIP дотор дэд хавтас байж болохгүй.
- **Сангууд:** `torch`, `torchvision`, `timm`. 

## 5. Оноолт

Эцсийн оноог дараах байдлаар тооцно. `M` нь хуваалт дахь зургийн тоо, $Score_A$ нь амжилттай A төрлийн пертурбацийн тоо, $Score_B$ нь амжилттай B төрлийн пертурбацийн тоо байг:
$$
S_{final} = \frac{Score_A + Score_B}{2M} \times PF
$$

PF нь өндөр нормтой пертурбацийг торгох, гүйцэтгэлийн дээд хязгаарын ойролцоо маш мэдрэмтгий байхаар зохиосон функц юм. Энэ нь энэ нь 0.5-аас 1 хүртэлх мужид хязгаарлагдана. Бүрэн хэрэгжүүлэлтийг `solution.ipynb`-ийн  8-р хэсгээс харж болно.
