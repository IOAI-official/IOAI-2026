# ภาวะกลืนไม่เข้าคายไม่ออกของสายลับสองหน้า

- **เวลาจำกัด:** 12 นาที

- **สภาพแวดล้อม:** GPU หนึ่งตัว (VRAM ≈16 GB), ไม่มีอินเทอร์เน็ต
- **ขนาดไฟล์คำตอบ:** `solution.ipynb` ≤ 1 MB
- **คะแนน baseline:** 0 
- **คะแนนของคณะกรรมการวิทยาศาสตร์:** 96.99 

ที่ศูนย์ AI แห่งชาติในอัสตานา โมเดลคอมพิวเตอร์สองโมเดล ได้แก่ Model R (ResNet-18) และ Model V (ViT-Tiny) กำลังวิเคราะห์ภาพถ่าย ขณะนี้ทั้งสองโมเดลทำงานได้อย่างสมบูรณ์แบบ โดยมีความแม่นยำ 100% และให้ผลตรงกันในทุกภาพ เพื่อทดสอบว่า "สมอง" อันชาญฉลาดของทั้งสองแตกต่างกันจริง ๆ มากเพียงใด หัวหน้านักวิทยาศาสตร์จึงมอบความท้าทายให้คุณ: ทำการเปลี่ยนแปลงพิกเซลเล็กน้อยจนแทบมองไม่เห็นในแต่ละภาพ เพื่อให้ Model R และ Model V ให้ผลไม่ตรงกันโดยสิ้นเชิง

![ภาพ](../../dilemma.jpg)

## 1. โจทย์

ตัวจำแนกภาพ (image classifier) ที่ผ่านการฝึกล่วงหน้าสองตัวพิจารณาภาพเดียวกัน สำหรับภาพที่ให้มาในโจทย์นี้ ตัวจำแนกทั้งสองมีความแม่นยำ 100%

- **Model R**: `torchvision.models.resnet18` (CNN, ResNet18)
- **Model V**: `timm` ของ `vit_tiny_patch16_224` (Transformer, ViT-Tiny)

งานของคุณคือสร้างการเปลี่ยนแปลงขนาดเล็ก ("การรบกวน" (perturbation)) สำหรับแต่ละภาพ เพื่อให้ทั้งสองโมเดลให้ผลไม่ตรงกัน สำหรับทุกภาพ คุณต้องสร้างการรบกวนที่**แตกต่างกันสองแบบ**:

- **ประเภท A**: หลังจากเพิ่มการรบกวนแล้ว Model R ยังคงจำแนกภาพได้อย่างถูกต้อง แต่ Model V จำแนกภาพผิด
- **ประเภท B**: หลังจากเพิ่มการรบกวนแล้ว Model V ยังคงจำแนกภาพได้อย่างถูกต้อง แต่ Model R จำแนกภาพผิด

การรบกวนแต่ละรายการต้องมีขนาด*เล็ก*เพียงพอที่จะสังเกตเห็นได้ยาก การรบกวนที่เล็กกว่าจะได้คะแนนสูงกว่า (ดูส่วนที่ 5) การรบกวนจะถูกนำไปใช้กับภาพต้นฉบับโดยตรงในระดับพิกเซล

## 2. ข้อมูลสาธารณะ

โจทย์นี้มีชุดภาพให้ โดยแบ่งเป็นสองส่วน ได้แก่ `train` (100 ภาพ) และ
`test_public` (100 ภาพ) ซึ่งแต่ละส่วนประกอบด้วยภาพที่มีความละเอียดแตกต่างกัน ภาพทั้งหมดมาจาก 1000 คลาสของ ImageNet-1K และทั้ง Model R และ Model V มีความแม่นยำ 100% บนทั้งสองส่วน

มีไฟล์ต่อไปนี้ให้:

```text
train/images/*.png         # 100 images in PNG format
train/labels.json          # maps each image index to its correct class
test_public/images/*.png   # 100 images in PNG format
test_public/labels.json    # maps each image index to its correct class
```

ระหว่างการตรวจให้คะแนน โฟลเดอร์ `dataset/test_public/` ของคุณจะถูกแทนที่อย่างโปร่งใสด้วยชุดภาพลับสองชุด (`test_leaderboard_a` และ `test_leaderboard_b`) สำหรับการให้คะแนนอย่างเป็นทางการ แต่ละชุดมี**100 ภาพ**ในรูปแบบ PNG และไฟล์ป้ายกำกับ 

**หมายเหตุ: สำหรับโจทย์นี้ สามารถเข้าถึงป้ายกำกับในชุดข้อมูลทดสอบได้**

## 3. รูปแบบเอาต์พุต

สำหรับแต่ละภาพ คุณต้องสร้างไฟล์สองไฟล์:

```text
{index}_a.pt   # Type A perturbation
{index}_b.pt   # Type B perturbation
```

- `{index}` (`0`, `1`, `2`, ...) ตรงกับชื่อของภาพในชุดข้อมูล
- แต่ละไฟล์เป็น tensor เดี่ยวที่บันทึกด้วย `torch.save` โดยต้องมีรูปร่างเป็น`3 x H x W` ซึ่ง `H` และ `W` ตรงกับความละเอียด**ต้นฉบับ**ของภาพนั้น (ไม่ใช่ `224 x 224`)
- โค้ดควรสร้างไฟล์ ZIP เพียงไฟล์เดียว คือ `submission.zip` ให้วางไฟล์ `.pt` ทั้งหมดไว้ที่ระดับบนสุดของไฟล์เก็บถาวร ZIP โดยไม่มีโฟลเดอร์ครอบหรือไดเรกทอรีย่อย 

```text
submission.zip
├── 0_a.pt
├── 0_b.pt
└── 1_a.pt
└── ...
```

โน้ตบุ๊ก (notebook) จะแจ้งเตือนคุณหากมีปัญหาใด ๆ เกี่ยวกับรูปแบบเอาต์พุต

## 4. ข้อจำกัด

- **โมเดล:** คุณต้องใช้ `torchvision.models.resnet18(pretrained=True)` และ `timm.create_model('vit_tiny_patch16_224', pretrained=True)` ไม่อนุญาตให้ใช้โมเดลอื่นที่ผ่านการฝึกล่วงหน้า
- **ลำดับขั้นการแปลง (บังคับใช้ระหว่างการประเมิน):** `Resize(256) → CenterCrop(224) →
  Normalize(mean=[0.485,0.456,0.406], std=[0.229,0.224,0.225])`. See Section 3 of `baseline.ipynb` สำหรับรายละเอียด 
- **ความละเอียดของการรบกวน:** ต้องตรงกับความละเอียดของภาพดิบ**ต้นฉบับ** (ไม่ใช่ 224×224) โดย tensor จะถูกเพิ่มลงในภาพดิบ*ก่อน*ลำดับขั้นการแปลง
- **รูปแบบเอาต์พุต:** เฉพาะไฟล์ `.pt` เท่านั้น — ห้ามใช้ PNG/JPG โดย tensor จะถูกเพิ่มลงในภาพดิบ และค่าพิกเซลจะถูกตัดให้อยู่ในช่วง `[0, 1]` ก่อนการประมวลผลเบื้องต้น
- **การตั้งชื่อไฟล์:** จัดเรียงแบบแบน โดยใช้รูปแบบ `{index}_a.pt` / `{index}_b.pt` อย่างเคร่งครัด ห้ามมีไดเรกทอรีย่อยภายในไฟล์ zip
- **ไลบรารี:** `torch`, `torchvision`, `timm` 

## 5. การให้คะแนน

คะแนนสุดท้ายคำนวณดังต่อไปนี้ ให้ `M` เป็นจำนวนภาพในส่วนนั้น $Score_A$ เป็นจำนวนการรบกวนประเภท A ที่สำเร็จ และ $Score_B$ เป็นจำนวนการรบกวนประเภท B ที่สำเร็จ:
$$
S_{final} = \frac{Score_A + Score_B}{2M} \times PF
$$

PF เป็นฟังก์ชันที่ออกแบบมาเพื่อลงโทษการรบกวนที่มีนอร์มสูง และมีความไวมากเมื่อประสิทธิภาพเข้าใกล้ค่าสูงสุด ฟังก์ชันนี้ถูกจำกัดให้อยู่ในช่วง 0.5 ถึง 1 สามารถดูการนำไปใช้ฉบับเต็มได้ในส่วนที่  8 ของ `solution.ipynb`
