# 기계의 유령

- **시간:** 10분
- **베이스라인 점수:** 28.6
- **환경:** GPU 1대(≈16 GB VRAM), 인터넷 없음
- **솔루션 크기:** `solution.ipynb` ≤ 20 MB
- **공간:** 5 GB
- **사전학습 모델:** **[bge-base-en-v1.5](https://yastatic.net/s3/contest/ioai/5/01_BAAI_bge-base-en-v1.5_MODEL_CARD.html)** 만 사용 가능, 텍스트 **encoder**(임베딩 모델).


## 과제

카자흐스탄 국립 기록보관소에서 사서들 왈 일부 책의 결말이 예전에는 달랐다고 말하는데 아무도 입증 불가능함, 모든 사본이 동일, 모든 이야기가 말이 되기 때문임. 그러한 변경점을 찾아내야함
![유령](../ghost.jpg)

하나의 지문은 사람이 쓴 텍스트로 시작, 어느 시점에서 조용히 언어 모델이 생성한
내용으로 전환됨. 전체 읽으면 일관된 글처럼 보이지만, 중간 어딘가에서
저자가 사람에서 기계로 바뀜. 과제는 **전환 지점, 즉 사람이 쓴 부분이 끝나고
기계가 쓴 부분이 시작되는 문자 인덱스를 찾는 것**.

각 샘플은 하나의 문자열 `text` 임. 경계는 단 하나만 존재. 그 앞의 모든 내용은
사람이 썼으며 그 지점부터의 모든 내용은 기계가 생성했음

## 데이터셋

일반 텍스트 형식의 영어 지문이며, 각각 경계가 하나씩 존재함

- **Part A**(경계 이전): 사람이 쓴 텍스트
- **Part B**(경계 이후): Part A 이후 언어 모델이 생성한 텍스트
- 각 부분은 최소 180 단어, 전체 길이는 약 500~800 단어
- **`boundary_char_index`** 는 Part A가 끝나는 문자 오프셋임
  `text[:boundary_char_index]` 은 사람이 쓴 부분
  `text[boundary_char_index:].lstrip()` 는 기계가 쓴 부분

#### 제공되는 것

**두 개의 폴더**를 받음:

| 폴더 | 샘플 수 | `answers.jsonl`? | 용도 |
|--------|---------|------------------|-----------|
| `dataset/train/` | 1,221 | ✅ 포함 | 방법을 학습 / 파인튜닝 |
| `dataset/test_public/`  | 380   | ✅ 포함 (dev 사본) | 파이프라인을 실행하고 로컬에서 자체 채점 |

**채점 시점**에는 `dataset/test_public/` 폴더가 **숨겨진 평가 세트로 교체됨**.
형식은 동일하지만 **`answers.jsonl` 는 없음**. 노트북이 그 위에서 다시 실행됨, 노트북이 생성한 `answers.jsonl` 이 채점됨

- 공개 리더보드는 숨겨진 **test_leaderboard_a** 세트(380 샘플)를 사용

- 최종 순위는 숨겨진 **test_leaderboard_b** 세트(380 샘플)를 사용

세 평가 세트는 모두 크기가 같고 `train` 과 동일한 분포에서 추출되었음, 로컬
`dataset/test_public/` 점수는 리더보드 점수에 대한 합리적 추정치로 쓸 수 있음

#### 디스크 상의 형식

```
dataset/train/data.jsonl      # one JSON object per line: {"id": "...", "text": "..."}
dataset/train/answers.jsonl   # {"id": "...", "boundary_char_index": 1842}
dataset/test_public/data.jsonl       # {"id": "...", "text": "..."}
dataset/test_public/answers.jsonl    # dev copy only — ABSENT in the hidden grading set
```

- `answers.jsonl` 의 id는 `data.jsonl` 의 id와 일치함
- `dataset/train/` (정답 포함)은 학습이나 파인튜닝을 할 때 언제든 사용 가능

## 출력 (제출 형식)

**노트북 파일 하나를 제출, 이름은 반드시 `solution.ipynb` 이어야함**. 정확한 파일 이름이 요구됨. 그 외의 것은 거부됨

여러분의 노트북은 **`dataset/test_public/data.jsonl` 을 읽고**, 저장소 루트에 단일 파일
**`answers.jsonl`** 을 작성해야함 한 줄에 하나의 JSON 객체로, 각 샘플 id를
여러분이 예측한 경계 문자 인덱스에 매핑함

```json
{"id": "example_000123", "boundary_char_index": 1790}
{"id": "example_000124", "boundary_char_index": 2450}
```

- `boundary_char_index` 는 **`[0, len(text)]` 범위의 정수**여야함
- `dataset/test_public/data.jsonl` 의 모든 id는 정확히 한 번씩 나타나야 함. `answers.jsonl` 에서 누락된 샘플 (또는 정수가 아니거나 범위 벗어난 값을 가진 샘플)은 해당 샘플에 대해 0점을 받음

## 채점

각 샘플에 대해 `p` 를 여러분의 예측 인덱스, `t` 를 실제 경계라고 할 시. 샘플별 점수는 문자 거리에 따라 지수적으로 감소함:

$$\text{score} = \exp\!\left(-\frac{|p - t|}{\tau}\right) \in (0, 1], 
~ \text{where} ~ \tau = 100.$$

따라서 점수는 다음과 같음:
- **=1.0** — 경계 문자를 정확히 맞춘 경우;
- **≈0.78** — 25 문자 차이; - **≈0.61** — 50 문자 차이;
- **≈0.37** — 100 문자 차이;
- **≈0.01** — 500 문자 차이.

**최종 점수는** 해당 분할의 모든 샘플에 대한 샘플별 점수의 **평균**임
(0–100 스케일임). 따라서 *가깝게* 맞히는 것도 점수 줌

  모델(아래)은 이미 제공되어 있습니다. **실제 소요 시간 예산: 전체 실행에 10분** —

- **허용된 사전학습 모델** — 이 목록이 전부이며, 그 외의 사전학습 가중치는
  사용 불가. 해당 모델은 **환경에 미리 제공되어 있음**(평소처럼 로드하십시오, 예:
  `from_pretrained`; 채점 시점에는 인터넷이 없습니다):
  - **bge-base-en-v1.5** — 파라미터 1억 1천만 개(110M)의 텍스트 **encoder**(임베딩 모델). 이 모델은
    문장/지문 임베딩을 생성하며, 생성형 언어 모델이 아님. 이 모델을
    **그대로(고정된 피처로) 사용하거나 `train` 분할에서 파인튜닝**할 수 있음
    (전체 파인튜닝은 16 GB / 10분 에 들어감).
- 고전적 / 통계적 도구는 제한 없음 : 여러분이 직접 계산한 임베딩 피처 위에
  임의의 피처 기반 모델(예: scikit-learn 분류기 또는 회귀기)을 구축 가능함
  *사전학습된 딥러닝 가중치*만 위 목록으로 제한됨
