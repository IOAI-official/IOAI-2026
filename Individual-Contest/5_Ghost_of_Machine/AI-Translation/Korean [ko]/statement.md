# 기계의 유령

- **제한 시간:** 10분
- **베이스라인 점수:** 28.6
- **Scientific Committee 점수:** 93.41
- **환경:** GPU 1대(≈16 GB VRAM), 인터넷 없음
- **솔루션 크기:** `solution.ipynb` ≤ 20 MB
- **저장 공간:** 5 GB
- **사전학습 모델:** **[bge-base-en-v1.5](https://yastatic.net/s3/contest/ioai/5/01_BAAI_bge-base-en-v1.5_MODEL_CARD.html)** 만 사용 가능 — 텍스트 **encoder**(임베딩 모델).


## 과제

카자흐스탄 국립 기록보관소에서 이상한 일이 벌어지고 있습니다. 사서들은 일부 책의 결말이 예전에는 달랐다고 말하지만, 아무도 이를 입증하지 못합니다 — 모든 사본이 동일하고, 모든 이야기는 여전히 말이 되기 때문입니다. 여러분은 그 변경 지점을 찾아내기 위해 AI 연구자로 초청되었습니다.
![유령](../../ghost.jpg)

하나의 지문은 사람이 쓴 텍스트로 시작하여, 어느 시점에서 조용히 언어 모델이 생성한
이어쓰기로 전환됩니다. 전체를 읽으면 하나의 일관된 글처럼 보이지만, 중간 어딘가에서
저자가 사람에서 기계로 바뀝니다. 여러분의 과제는 **그 전환 지점, 즉 사람이 쓴 부분이 끝나고
기계가 쓴 부분이 시작되는 문자 인덱스를 찾는 것**입니다.

각 샘플은 하나의 문자열 `text`입니다. 경계는 정확히 하나만 존재합니다. 그 앞의 모든 내용은
사람이 쓴 것이고, 그 지점부터 이후의 모든 내용은 기계가 생성한 것입니다.

## 데이터셋

일반 텍스트 형식의 영어 지문이며, 각각 경계가 하나씩 있습니다.

- **Part A**(경계 이전): 사람이 쓴 텍스트의 발췌.
- **Part B**(경계 이후): Part A를 조건으로 하여 언어 모델이 생성한 이어쓰기.
- 각 부분은 최소 180 단어이며, 전체 길이는 약 500–800 단어입니다.
- **`boundary_char_index`** 는 Part A가 끝나는 문자 오프셋입니다:
  `text[:boundary_char_index]` 은 사람이 쓴 부분이고,
  `text[boundary_char_index:].lstrip()` 는 기계가 쓴 부분입니다.

#### 제공되는 것

**두 개의 폴더**를 받습니다:

| 폴더 | 샘플 수 | `answers.jsonl`? | 용도 |
|--------|---------|------------------|-----------|
| `dataset/train/` | 1,221 | ✅ 포함 | 방법을 학습 / 파인튜닝 |
| `dataset/test_public/`  | 380   | ✅ 포함 (dev 사본) | 파이프라인을 실행하고 로컬에서 자체 채점 |

**채점 시점**에는 여러분의 `dataset/test_public/` 폴더가 **숨겨진 평가 세트로 교체됩니다**.
형식은 동일하지만 **`answers.jsonl` 는 없습니다**. 여러분의
노트북이 그 위에서 다시 실행되며, 노트북이 생성한 `answers.jsonl` 이 채점됩니다.

- 공개 리더보드는 숨겨진 **test_leaderboard_a** 세트(380 샘플)를 사용합니다.

- 최종 순위는 숨겨진 **test_leaderboard_b** 세트(380 샘플)를 사용합니다.

세 평가 세트는 모두 크기가 같고 `train` 과 동일한 분포에서 추출되었으므로, 로컬의
`dataset/test_public/` 점수는 리더보드 점수에 대한 합리적인 추정치가 됩니다.

#### 디스크 상의 형식

```
dataset/train/data.jsonl      # one JSON object per line: {"id": "...", "text": "..."}
dataset/train/answers.jsonl   # {"id": "...", "boundary_char_index": 1842}
dataset/test_public/data.jsonl       # {"id": "...", "text": "..."}
dataset/test_public/answers.jsonl    # dev copy only — ABSENT in the hidden grading set
```

- `answers.jsonl` 의 id는 `data.jsonl` 의 id와 일치합니다.
- `dataset/train/` (정답 포함)은 학습이나 파인튜닝을 할 때 언제든 사용할 수 있습니다.

## 출력 (제출 형식)

**노트북 파일 하나를 제출하며, 그 이름은 반드시 `solution.ipynb` 이어야 합니다**. 이 정확한 파일 이름이 요구됩니다. 그 외의 것은 실행되지 않고 거부됩니다.

여러분의 노트북은 **`dataset/test_public/data.jsonl` 을 읽고**, 저장소 루트에 단일 파일
**`answers.jsonl`** 을 작성해야 합니다 — 한 줄에 하나의 JSON 객체로, 각 샘플 id를
여러분이 예측한 경계 문자 인덱스에 매핑합니다:

```json
{"id": "example_000123", "boundary_char_index": 1790}
{"id": "example_000124", "boundary_char_index": 2450}
```

- `boundary_char_index` 는 **`[0, len(text)]` 범위의 정수**여야 합니다.
- `dataset/test_public/data.jsonl` 의 모든 id는 정확히 한 번씩 나타나야 합니다. `answers.jsonl` 에서 누락된 샘플
  (또는 정수가 아니거나 범위를 벗어난 값을 가진 샘플)은 해당 샘플에 대해 0점을
  받습니다.

## 채점

각 샘플에 대해 `p` 를 여러분의 예측 인덱스, `t` 를 실제 경계라고 합시다. 샘플별 점수는 문자 거리에 따라 지수적으로 감소합니다:

$$\text{score} = \exp\!\left(-\frac{|p - t|}{\tau}\right) \in (0, 1], 
~ \text{where} ~ \tau = 100.$$

이로 인해 점수는 다음과 같이 동작합니다:
- **=1.0** — 경계 문자를 정확히 맞춘 경우;
- **≈0.78** — 25 문자 차이; - **≈0.61** — 50 문자 차이;
- **≈0.37** — 100 문자 차이;
- **≈0.01** — 500 문자 차이.

**최종 점수는** 해당 분할의 모든 샘플에 대한 샘플별 점수의 **평균**입니다
(0–100 척도로 보고됨). 이 지표는 정확히 맞히는 것뿐 아니라 *가깝게* 맞히는 것에도 보상을 줍니다.

## 제약 조건

- **환경:** GPU 1대(≈16 GB VRAM), 채점 시점에 인터넷 없음 — 허용된
  모델(아래)은 이미 제공되어 있습니다. **실제 소요 시간 예산: 전체 실행에 10분** —
  이 시간 안에 채점 시점에 수행하는 모든 학습 / 파인튜닝 **및** 평가 세트에 대한
  추론이 모두 포함되어야 합니다.
- **허용된 사전학습 모델** — 이 목록이 전부이며, 그 외의 사전학습 가중치는
  사용할 수 없습니다. 해당 모델은 **환경에 미리 제공되어 있습니다**(평소처럼 로드하십시오, 예:
  `from_pretrained`; 채점 시점에는 인터넷이 없습니다):
  - **bge-base-en-v1.5** — 파라미터 1억 1천만 개(110M)의 텍스트 **encoder**(임베딩 모델). 이 모델은
    문장/지문 임베딩을 생성하며, 생성형 언어 모델이 아닙니다. 이 모델을
    **그대로(고정된 피처로) 사용하거나 `train` 분할에서 파인튜닝**할 수 있습니다
    (전체 파인튜닝은 16 GB / 10분 예산 안에 들어갑니다).
- 고전적 / 통계적 도구는 제한이 없습니다: 여러분이 직접 계산한 임베딩 피처 위에
  임의의 피처 기반 모델(예: scikit-learn 분류기 또는 회귀기)을 구축할 수 있습니다.
  *사전학습된 딥러닝 가중치*만 위 목록으로 제한됩니다.

## 베이스라인

제공된 `solution.ipynb` 은 사소한 참고용입니다: 이는 `dataset/train/` 로부터 단일한
"평균 경계 비율"을 추정하고, 모든 테스트 지문에 대해 길이의 그 동일한 비율을
예측합니다. 이는 숨겨진 **test_leaderboard_a** 분할에서 **28.6** 점을 받으며,
`dataset/test_public/` 읽기 → `answers.jsonl` 쓰기 루프를 위한 실행 가능한 템플릿으로만
존재합니다.

**Scientific Committee 점수 93.41** 은 동일한 분할과 동일한 10분 예산에서 측정된 것으로,
허용된 encoder를 `train` 에서 파인튜닝하고 문장 단위의 변화점(changepoint)으로 전환 지점을
찾아내어 얻은 결과입니다. 이는 상한이 아니며 — 이 지표의 최댓값은 100입니다.
