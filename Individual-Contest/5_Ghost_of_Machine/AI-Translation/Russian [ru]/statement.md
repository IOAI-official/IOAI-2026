# Призрак машины

- **Ограничение по времени:** 10 минут
- **Бейзлайн-результат:** 28.6
- **Результат Научного комитета:** 93.41
- **Среда:** один GPU (≈16 GB VRAM), без доступа к интернету
- **Размер решения:** `solution.ipynb` ≤ 20 MB
- **Хранилище:** 5 GB
- **Предобученные модели:** только **[bge-base-en-v1.5](https://yastatic.net/s3/contest/ioai/5/01_BAAI_bge-base-en-v1.5_MODEL_CARD.html)** — текстовый **энкодер** (модель эмбеддингов).


## Задача

В Национальном архиве Казахстана происходят странные вещи. Библиотекари утверждают, что раньше некоторые книги заканчивались иначе, но никто не может этого доказать — все экземпляры одинаковы, и каждый рассказ по-прежнему имеет смысл. Вас пригласили в качестве исследователя ИИ, чтобы обнаружить изменения.
![Призрак](../../ghost.jpg)

Отрывок начинается как текст, написанный человеком, а затем в некоторый момент незаметно переходит
в продолжение, сгенерированное языковой моделью. При прочтении целиком он выглядит как
единый связный текст — но где-то в середине автор меняется с человека
на машину. Ваша задача — **найти этот переход: индекс символа, на котором
заканчивается написанная человеком часть и начинается машинная часть**.

Каждый пример представляет собой одну строку `text`. Существует ровно одна граница. Всё,
что находится до неё, написано человеком; всё, начиная с неё, сгенерировано машиной.

## Датасет

Англоязычные отрывки в виде обычного текста, по одной границе в каждом.

- **Часть A** (до границы): фрагмент текста, написанного человеком.
- **Часть B** (начиная с границы): продолжение, созданное языковой моделью
  при условии Части A.
- Каждая часть содержит не менее 180 слов; общая длина составляет ~500–800 слов.
- **`boundary_char_index`** — это смещение в символах, на котором заканчивается Часть A:
  `text[:boundary_char_index]` — часть, написанная человеком, а
  `text[boundary_char_index:].lstrip()` — машинная часть.

#### Что вы получаете

Вы получаете **две папки**:

| Папка | Примеры | `answers.jsonl`? | Использование |
|--------|---------|------------------|-----------|
| `dataset/train/` | 1,221 | ✅ включены | обучение / дообучение вашего метода |
| `dataset/test_public/`  | 380   | ✅ включены (копия для разработки) | запуск вашего пайплайна и самостоятельная локальная оценка |

Во время проверки ваша папка `dataset/test_public/` **заменяется скрытым
оценочным набором**. Он имеет тот же формат, но **без `answers.jsonl`**. Ваш
ноутбук запускается на нём повторно, и созданный им `answers.jsonl` оценивается.

- Для публичной таблицы лидеров используется скрытый набор **test_leaderboard_a** (380 примеров).

- Для итогового рейтинга используется скрытый набор **test_leaderboard_b** (380 примеров).

Все три оценочных
набора имеют одинаковый размер и взяты из того же распределения, что и `train`, поэтому ваша локальная
оценка `dataset/test_public/` является разумной оценкой вашего результата в таблице лидеров.

#### Формат на диске

```
dataset/train/data.jsonl      # one JSON object per line: {"id": "...", "text": "..."}
dataset/train/answers.jsonl   # {"id": "...", "boundary_char_index": 1842}
dataset/test_public/data.jsonl       # {"id": "...", "text": "..."}
dataset/test_public/answers.jsonl    # dev copy only — ABSENT in the hidden grading set
```

- Идентификаторы в `answers.jsonl` соответствуют идентификаторам в `data.jsonl`.
- `dataset/train/` (с ответами) доступен всякий раз, когда вы обучаете или дообучаете модель.

## Вывод (формат посылки)

Вы отправляете **один ноутбук, который должен называться `solution.ipynb`**. Требуется именно это имя файла. Всё остальное отклоняется без запуска.

Ваш ноутбук должен **прочитать `dataset/test_public/data.jsonl`** и записать один файл
**`answers.jsonl`** в корне репозитория — по одному объекту JSON в каждой строке, сопоставляя
идентификатор каждого примера с предсказанным вами индексом символа границы:

```json
{"id": "example_000123", "boundary_char_index": 1790}
{"id": "example_000124", "boundary_char_index": 2450}
```

- `boundary_char_index` должен быть **целым числом в `[0, len(text)]`**.
- Каждый идентификатор из `dataset/test_public/data.jsonl` должен встречаться ровно один раз. Пример, отсутствующий
  в `answers.jsonl` (либо имеющий нецелое значение / значение вне допустимого диапазона), получает 0
  баллов за этот пример.

## Оценивание

Для каждого примера пусть `p` — предсказанный вами индекс, а `t` — истинная граница. Оценка за пример экспоненциально убывает с увеличением расстояния в символах:

$$\text{score} = \exp\!\left(-\frac{|p - t|}{\tau}\right) \in (0, 1], 
~ \text{where} ~ \tau = 100.$$

Это приводит к следующему поведению оценки:
- **=1.0** — точный символ границы;
- **≈0.78** — ошибка на 25 символов; - **≈0.61** — ошибка на 50 символов;
- **≈0.37** — ошибка на 100 символов;
- **≈0.01** — ошибка на 500 символов.

**Итоговая оценка представляет собой среднее значение** оценок за все примеры в выборке
(представленное по шкале 0–100). Метрика поощряет близость к границе, а не только точное совпадение.

## Ограничения

- **Среда:** один GPU (≈16 GB VRAM), без доступа к интернету во время проверки — разрешённая
  модель (указанная ниже) уже предоставлена. **Ограничение по реальному времени: 10 минут** на
  весь запуск — сюда должны входить любое обучение / дообучение, выполняемое вами во время проверки,
  **а также** инференс на оценочном наборе.
- **Разрешённая предобученная модель** — список исчерпывающий; никакие другие предобученные веса
  использовать нельзя. Она **заранее предоставлена в среде** (загрузите её обычным способом, например
  `from_pretrained`; во время проверки доступа к интернету нет):
  - **bge-base-en-v1.5** — текстовый **энкодер** (модель эмбеддингов) со 110M параметров. Он
    создаёт эмбеддинги предложений/отрывков; это не генеративная языковая модель. Вы
    можете использовать его **как есть (с замороженными признаками) или дообучить на выборке `train`**
    (полное дообучение укладывается в ограничения 16 GB / 10 минут).
- Классические / статистические инструменты не ограничены: вы можете построить любую модель на основе
  признаков (например, классификаторы или регрессоры scikit-learn) поверх самостоятельно
  вычисленных признаков-эмбеддингов. Ограничение только перечисленными выше моделями распространяется на *предобученные веса глубокого обучения*.

## Бейзлайн

Предоставленный `solution.ipynb` — тривиальный ориентир: он оценивает единственную
«среднюю долю границы» по `dataset/train/` и для каждого тестового отрывка предсказывает ту же долю
его длины. Он набирает **28.6** на скрытой выборке
**test_leaderboard_a** и существует только как запускаемый шаблон для цикла
чтение-`dataset/test_public/` → запись-`answers.jsonl`.

**Результат Научного комитета 93.41**, измеренный на той же выборке при том же
ограничении в 10 минут, получен путём дообучения разрешённого энкодера на `train` и определения
перехода как точки изменения по предложениям. Это не верхняя граница — максимальная
оценка по этой метрике равна 100.
