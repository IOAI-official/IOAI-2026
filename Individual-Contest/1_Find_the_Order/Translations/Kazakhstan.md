# Ретті табу

- **Уақыт шектеуі:** 10 минут
- **Орта:** бір GPU (≈16 GB VRAM), интернет жоқ
- **Шешім өлшемі:** `solution.ipynb` ≤ 1 MB
- **Сақтау орны:** 5 GB 

## Есеп

Сізге екі қатысушының, *Speaker A* және *Speaker B*, ағылшын тіліндегі ауыз-екі диалогтары беріледі. Әр диалог сөйлеушілердің репликаларына бөлінген, әр репликада тек бір сөйлеушінің сөзі бар. Әр реплика жеке `.wav` аудиофайлы ретінде сақталады, сондықтан толық диалог әр репликаға бір-бірден сәйкес келетін `.wav` файлдарының жиынымен ұсынылады. 

Өкінішке қарай, репликалар кездейсоқ араластырылған, сондықтан әңгіме енді мағыналы емес. `chunk_{k}.wav` файл атауында `k` бастапқы диалогтағы k-ші репликаны емес, араластырылған жиындағы k-ші фрагментті білдіреді.

**‼️ Сіздің міндетіңіз — әңгіменің бастапқы хронологиялық ретін қалпына келтіру.**

## Датасет
Әр диалогта `n`  аудио файлдар бар, `chunk_0.wav`, `chunk_1.wav`, …, `chunk_{n-1}.wav` деп аталады. Фрагментер(chunk) - бір реплика. Файл атаулары тек араластырылған ретке сәйкес келеді. Олар фрагменттің бастапқы әңгімеде қай жерде орналасатынын көрсетпейді. Әр диалогта 7–20 фрагмент бар, моно, 44.1 kHz (қайта
дискреттеуге болады).

**`prefix.json` әр диалогтағы алғашқы екі фрагменттің файл атауы индекстерін қамтиды.** Бұл диалогтың шынайы басталуын анықтайды және әңгімені алға немесе кері бағытта оқу арасындағы екіұштылықты жояды.

Мысалы: `11: [7, 12]` дегеніміз 11-диалогтың бірінші және екінші репликалары тиісінше `chunk_7.wav` және `chunk_12.wav` екенін білдіреді.

### Сізге берілетіндер

Сізге **құрылымы бірдей екі бума** беріледі:

| Бума | Диалогтар | `answers.json` бар ма? | Қолданылуы |
|--------|-----------|-----------------|-----------|
| `dataset/train/` | 1,288 | ✅ қамтылған | моделіңізді оқыту / жете оқыту |
| `dataset/test_public/`  | 100   | ✅ қамтылған | пайплайныңызды іске қосу және нәтижені жергілікті түрде өзіңіз бағалау |

Бағалау кезінде `dataset/test_public/` бумаңыз автоматты түрде
`hidden evaluation set` бумасымен (жария лидерборд үшін `test_leaderboard_a` және қорытынды лидерборд үшін `test_leaderboard_b`) ауыстырылады — олардың өлшемі мен құрылымы `dataset/test_public/` папкасымен бірдей, бірақ `answers.json` жоқ.

Ноутбугыңыз осы деректерде қайта орындалады және ол жасайтын `answers.json` файлы бағалау үшін пайдаланылады. Кейінге қалдырылған тест диалогтары `train` сияқты үлестірімнен алынған, сондықтан жергілікті `test_public` нәтижеңіз — алдағы нәтиженің сенімді көрсеткіші.

### Каталог құрылымы

```bash
dataset/train/
    prefix.json  # {dialogue_id: [first_idx, second_idx]} filename index 
    answers.json  # {dialogue_id: P}  ground-truth order (rank convention)
    <dialogue_id>/
        chunk_0.wav
        ...
        chunk_{n-1}.wav

dataset/test_public/
    prefix.json
    answers.json     # present only in the development copy
    <dialogue_id>/
        chunk_0.wav
        ...
        chunk_{n-1}.wav
```

## Шығыс

Әр диалог үшін оның аудиофрагменттерінің бастапқы хронологиялық ретін анықтаңыз. Болжамыңыз `{0, 1, …, n−1}` жиынының `P` перестановкасы болуы керек, мұндағы `P[i]` — `chunk_i.wav` фрагментінің болжанған хронологиялық орны (0 = бірінші).

Сіздің `answers.json` шығыс файлыңыз әр диалог идентификаторын оның болжанған перестановкасымен сәйкестендіруі керек:

```json
{
  "17": [2, 0, 1],
  "42": [0, 1],
  "108": [3, 1, 0, 4, 2, 5]
}
```

### Мысал

Диалогта араластырылған 3 `chunk_0, chunk_1, chunk_2` фрагменті бар:

| араластырылған фрагмент | айтылған мазмұн | шынайы орны (рангі) |
|----------------|----------------|----------------------|
| `chunk_0.wav` | *"No worries — I'll send you the notes afterwards."* | 2 (соңғы) |
| `chunk_1.wav` | *"Hey, are you coming to the three o'clock meeting?"* | 0 (бірінші) |
| `chunk_2.wav` | *"I can't — I've got a dentist appointment then."* | 1 |

Шынайы рет — **chunk_1 → chunk_2 → chunk_0**, сондықтан `P = [2, 0, 1]`, ал `prefix.json` құрамында `[1, 2]` бар.

⚠️ **P міндетті түрде дұрыс перестановка болуы керек:** ұзындығы n, индекстеу 0-ден басталады, әр мән дәл бір рет кездеседі. Қайталанатын, жетіспейтін немесе диапазоннан тыс элементтер (мысалы, индекстеу 1-ден басталса) сол диалог үшін 0 ұпай береді; файлда диалогтың болмауы да дәл осындай нәтиже береді. Пішімі дұрыс емес немесе JSON емес файл қабылданбайды.

## Бағалау

Бұл есептің бағалау метрикасы — **жұптық реттілік дәлдігі**. Ол фрагменттердің әр жұбын тексеріп: _екеуінің қайсысы бірінші болуы керек?_ — деген сұрақ қояды. Егер болжамыңыз эталондық жауаппен бірдей нәтиже берсе, жұп дұрыс деп есептеледі. `n` фрагменті бар диалогта $$M = n(n-1)/2$$ жұп болады; `I` — инверсиялар, яғни эталондық жауаптан өзгеше реттелген жұптар саны болсын:

$$\text{score} = 1 - \frac{I}{M} \in [0, 1]$$

ℹ️ **Қорытынды ұпай — бөліністегі барлық
диалог бойынша әр диалог ұпайларының орташа мәні.**

## Рұқсат етілген модельдер

Бұл есепті шешу үшін оқыту кезінде де, бағалау кезінде де тек келесі алдын ала оқытылған модельдерді пайдалана аласыз. Бұл модельдердің барлығы алдын ала жүктелген және ортада қолжетімді. Оларды пайдалану мысалдарын `solution.ipynb` baseline ноутбугынан көре аласыз. Басқа ешбір модельді пайдалануға болмайтынын және бағдарламаңызда интернетке қолжетімділік жоқ екенін ескеріңіз.

- **Сөйлеу репрезентациялары:** **wav2vec 2.0**. **Whisper encoder**-ін де белгілер экстракторы ретінде пайдалануға болады.
[wav2vec моделінің картасы](https://yastatic.net/s3/contest/ioai/1/01_facebook_wav2vec2-base-960h_MODEL_CARD.html)

- **Сөйлеуді автоматты түрде тану (ASR):** **OpenAI Whisper** (кез келген өлшемі).
[Whisper моделінің картасы](https://yastatic.net/s3/contest/ioai/1/03_openai_whisper-small_MODEL_CARD.html)
- **Тілдік модель:** **Qwen2.5-0.5B**, оны zero-shot режимінде немесе берілген `train` бөлінісінде жете оқытып пайдалануға болады.
[Qwen моделінің картасы](https://yastatic.net/s3/contest/ioai/1/02_Qwen_Qwen2.5-0.5B_MODEL_CARD.html)
10 минуттық шектеу бағалау кезінде орындайтын кез келген оқытуыңызды немесе жете оқытуыңызды, сондай-ақ бағалау жиынындағы инференсті қамтуы керек екенін ескеріңіз.
