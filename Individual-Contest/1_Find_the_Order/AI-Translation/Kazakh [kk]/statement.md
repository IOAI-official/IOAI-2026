# Реттілікті табу

- **Уақыт шектеуі:** 10 минут
- **Орта:** бір GPU (≈16 GB VRAM), интернетсіз
- **Шешім көлемі:** `solution.ipynb` ≤ 1 MB
- **Сақтау орны:** 5 GB

## Есеп

Сізге екі қатысушы — *Speaker A* және *Speaker B* — арасындағы ағылшын тіліндегі ауызша диалогтар беріледі. Әрбір диалог сөйлеуші кезектеріне (turn) бөлінген, әрбір кезекте тек бір сөйлеушінің сөзі болады. Әрбір кезек жеке `.wav` аудиофайл ретінде сақталған, сондықтан толық диалог `.wav` файлдар жиынымен, әр кезекке бір файлдан, беріледі.

Өкінішке орай, кезектер кездейсоқ түрде араластырылған, сондықтан әңгіме мағынасын жоғалтқан. `chunk_{k}.wav` файл атауындағы `k` араластырылған жиындағы k-шы chunk-ты білдіреді, бастапқы диалогтағы k-шы кезекті емес.

**‼️ Сіздің міндетіңіз — әңгіменің бастапқы хронологиялық ретін қалпына келтіру.**

## Дерекқор

Әрбір диалогта `chunk_0.wav`, `chunk_1.wav`, …, `chunk_{n-1}.wav` деп аталатын `n` аудиофайл бар. Chunk-тар — жеке кезектер. Файл атаулары тек араластырылған ретке сәйкес келеді. Олар chunk-тың бастапқы әңгімедегі орнын көрсетпейді. Әрбір диалогта 7–20 chunk бар, mono, 44.1 kHz (қайта дискреттеуге (resample) болады).

**`prefix.json` әр диалогтағы алғашқы екі chunk-тың файл атауы индекстерін қамтиды.** Бұл диалогтың нағыз басталуын анықтайды және әңгімені алға немесе кері қарай оқу арасындағы екіұштылықты жояды.

Мысалы: `11: [7, 12]` дегеніміз 11-диалогтың бірінші және екінші кезектері сәйкесінше `chunk_7.wav` және `chunk_12.wav` болатынын білдіреді.

### Сізге не беріледі

Сіз **бірдей форматтағы екі қалта** аласыз:

| Қалта | Диалогтар | `answers.json`? | Не үшін қолданылады |
|--------|-----------|-----------------|-----------|
| `dataset/train/` | 1,288 | ✅ қосылған | модельді оқыту / fine-tune жасау |
| `dataset/test_public/`  | 100   | ✅ қосылған | pipeline-ды іске қосу және жергілікті түрде өз нәтижеңізді бағалау |

Бағалау кезінде сіздің `dataset/test_public/` қалтаңыз мөлдір түрде `hidden evaluation set` (жария leaderboard үшін `test_leaderboard_a` және қорытынды leaderboard үшін `test_leaderboard_b`) қалтасымен ауыстырылады — олардың көлемі мен форматы `dataset/test_public/` сияқты, бірақ `answers.json` жоқ.

Сіздің ноутбугіңіз сол деректерде қайта орындалады және оның нәтижесінде шығатын `answers.json` файлы бағалау үшін пайдаланылады. Жасырын тест диалогтары `train` секілді бірдей таралымнан алынған, сондықтан сіздің жергілікті `test_public` ұпайыңыз шынайы алдын ала көрсеткіш болып табылады.

### Каталог құрылымы

```bash
dataset/train/
    prefix.json  # {dialogue_id: [first_idx, second_idx]} filename index 
    answers.json  # {dialogue_id: P}  ground-truth order (rank convention)
    <dialogue_id>/
        chunk_0.wav
        ...
        chunk_{n-1}.wav

dataset/test_public/
    prefix.json
    answers.json     # present only in the development copy
    <dialogue_id>/
        chunk_0.wav
        ...
        chunk_{n-1}.wav
```

## Шығыс

Әрбір диалог үшін оның аудио chunk-тарының бастапқы хронологиялық ретін анықтаңыз. Сіздің болжамыңыз `{0, 1, …, n−1}` жиынының `P` алмастыруы (permutation) болуы керек, мұнда `P[i]` — `chunk_i.wav` үшін болжанған хронологиялық орын (0 = бірінші).

Сіздің шығыс файлыңыз `answers.json` әрбір диалог ID-ін оның болжанған алмастыруына сәйкестендіруі керек:

```json
{
  "17": [2, 0, 1],
  "42": [0, 1],
  "108": [3, 1, 0, 4, 2, 5]
}
```

### Мысал

Диалогта 3 араластырылған chunk бар `chunk_0, chunk_1, chunk_2`:

| араластырылған chunk | айтылған мазмұн | нақты орын (ранг) |
|----------------|----------------|----------------------|
| `chunk_0.wav` | *«Уайымдама — жазбаларды саған кейін жіберемін.»* | 2 (соңғы) |
| `chunk_1.wav` | *«Сәлем, сағат үштегі кездесуге келесің бе?»* | 0 (бірінші) |
| `chunk_2.wav` | *«Келе алмаймын — сол уақытта тіс дәрігеріне жазылғанмын.»* | 1 |

Нағыз рет — **chunk_1 → chunk_2 → chunk_0**, сондықтан `P = [2, 0, 1]`, ал `prefix.json` `[1, 2]` мәнін ұстайды.

⚠️ **P нағыз алмастыру болуы керек:** ұзындығы n, 0-ден басталатын индекстеу, әрбір мән дәл бір рет. Қайталанулар, жетіспейтін мәндер немесе ауқымнан тыс жазбалар (мысалы, 1-ден басталатын индекстеу) сол диалог үшін 0 ұпай алады, файлда жоқ диалог та солай. Дұрыс құрылмаған немесе JSON емес файл қабылданбайды.

## Бағалау

Бұл тапсырманың бағалауы — **жұптық реттеу дәлдігі (pairwise ordering accuracy)**. Ол chunk-тардың әрбір жұбын тексеріп: _екеуінің қайсысы бірінші болуы керек?_ деп сұрайды. Егер сіздің болжамыңыз шынайы жауаппен бірдей нәтиже берсе, жұп дұрыс саналады. `n` chunk-тан тұратын диалог үшін $$M = n(n-1)/2$$ жұп болады; `I` инверсиялар саны болсын — яғни шынайы жауаптан өзгеше реттелген жұптар:

$$\text{score} = 1 - \frac{I}{M} \in [0, 1]$$

ℹ️ **Қорытынды ұпай — бөліктегі (split) барлық диалогтар бойынша әр диалогқа берілген ұпайлардың орташа мәні.**

## Рұқсат етілген модельдер

Бұл тапсырманы шешу үшін оқыту кезінде де, бағалау кезінде де тек төмендегі алдын ала оқытылған модельдерді пайдалана аласыз. Бұл модельдердің барлығы ортада алдын ала жүктелген және қолжетімді. Оларды қалай пайдалану керектігінің мысалдарын `solution.ipynb` baseline ноутбугінен көре аласыз. Ескеріңіз: басқа ешбір модельді пайдалана алмайсыз және бағдарламаңыздың интернетке қолжетімі жоқ.

- **Сөйлеу репрезентациялары:** **wav2vec 2.0**. Сондай-ақ **Whisper encoder** белгі (feature) шығарғыш ретінде пайдаланылуы мүмкін.
[wav2vec model card](https://yastatic.net/s3/contest/ioai/1/01_facebook_wav2vec2-base-960h_MODEL_CARD.html)

- **Автоматты сөйлеуді тану (ASR):** **OpenAI Whisper** (кез келген өлшемі).
[Whisper model card](https://yastatic.net/s3/contest/ioai/1/03_openai_whisper-small_MODEL_CARD.html)
- **Тілдік модель:** **Qwen2.5-0.5B**, оны zero-shot түрінде де, берілген `train` бөлігінде fine-tune жасап та пайдалануға болады.
[Qwen model card](https://yastatic.net/s3/contest/ioai/1/02_Qwen_Qwen2.5-0.5B_MODEL_CARD.html)
Ескеріңіз: 10 минуттық шектеу бағалау кезінде жасалатын кез келген оқытуды немесе fine-tune-ды, сондай-ақ бағалау жиынындағы инференсті қамтуы тиіс.
