## Задача

Вам надано усні діалоги англійською мовою між двома учасниками, *Спікером A* і *Спікером B*. Кожен діалог сегментовано на репліки, причому кожна репліка містить мовлення лише одного спікера. Кожна репліка зберігається як окремий аудіофайл `.wav`, тому повний діалог представлено набором файлів `.wav`, по одному для кожної репліки. 

На жаль, репліки було випадково перемішано, тому розмова більше не має сенсу. У назві файлу `chunk_{k}.wav`, `k` позначає k-й фрагмент у перемішаному наборі, а не k-ту репліку в початковому діалозі.

**‼️ Ваше завдання — відновити початковий хронологічний порядок розмови.**

## Датасет

Кожен діалог містить аудіофайли `n` з назвами `chunk_0.wav`, `chunk_1.wav`, …, `chunk_{n-1}.wav`. Фрагменти є окремими репліками. Назви файлів відповідають лише перемішаному порядку. Вони не вказують, де фрагмент розташовувався в початковій розмові. Кожен діалог має 7–20 фрагментів, моно, 44.1 kHz (ви можете
змінити частоту дискретизації).

**`prefix.json` містить індекси назв файлів перших двох фрагментів у кожному діалозі.** Це визначає справжній початок діалогу та усуває неоднозначність між прочитанням розмови у прямому та зворотному порядку.

Наприклад: `11: [7, 12]` означає, що першою та другою репліками діалогу 11 є відповідно `chunk_7.wav` і `chunk_12.wav`.

### Що ви отримуєте

Ви отримуєте **дві папки однакового формату**:

| Папка | Діалоги | `answers.json`? | Використання |
|--------|-----------|-----------------|-----------|
| `dataset/train/` | 1,288 | ✅ включено | навчання / донавчання вашої моделі |
| `dataset/test_public/`  | 100   | ✅ включено | запуск вашого конвеєра та локальне самостійне оцінювання |

Під час оцінювання ваша папка `dataset/test_public/` непомітно замінюється на
`hidden evaluation set` (`test_leaderboard_a` для публічної таблиці лідерів і `test_leaderboard_b` для фінальної таблиці лідерів) — вони мають такий самий розмір і формат, як `dataset/test_public/`, але без `answers.json`.

Ваш ноутбук знову виконується на цих даних, а створений ним файл `answers.json` використовується для оцінювання. Відкладені тестові діалоги походять із того самого розподілу, що й `train`, тому ваша локальна оцінка `test_public` є достовірним попереднім показником.

### Структура каталогів

```bash
dataset/train/
    prefix.json  # {dialogue_id: [first_idx, second_idx]} filename index 
    answers.json  # {dialogue_id: P}  ground-truth order (rank convention)
    <dialogue_id>/
        chunk_0.wav
        ...
        chunk_{n-1}.wav

dataset/test_public/
    prefix.json
    answers.json     # present only in the development copy
    <dialogue_id>/
        chunk_0.wav
        ...
        chunk_{n-1}.wav
```

## Вивід

Для кожного діалогу визначте початковий хронологічний порядок його аудіофрагментів. Ваше передбачення має бути перестановкою `P` множини `{0, 1, …, n−1}`, де `P[i]` — передбачена хронологічна позиція `chunk_i.wav` (0 = перший).

Ваш вихідний файл `answers.json` має зіставляти кожному ідентифікатору діалогу його передбачену перестановку:

```json
{
  "17": [2, 0, 1],
  "42": [0, 1],
  "108": [3, 1, 0, 4, 2, 5]
}
```

### Приклад

Діалог має 3 перемішані фрагменти `chunk_0, chunk_1, chunk_2`:

| перемішаний фрагмент | озвучений вміст | справжня позиція (ранг) |
|----------------|----------------|----------------------|
| `chunk_0.wav` | *"No worries — I'll send you the notes afterwards."* | 2 (останній) |
| `chunk_1.wav` | *"Hey, are you coming to the three o'clock meeting?"* | 0 (перший) |
| `chunk_2.wav` | *"I can't — I've got a dentist appointment then."* | 1 |

Справжній порядок — **chunk_1 → chunk_2 → chunk_0**, отже, `P = [2, 0, 1]`, а `prefix.json` містить `[1, 2]`.

⚠️ **P має бути справжньою перестановкою:** довжини n, з індексацією від 0, кожне значення — рівно один раз. Дублікати, відсутні значення або значення поза допустимим діапазоном (наприклад, з індексацією від 1) дають 0 балів за цей діалог, як і відсутність діалогу у файлі. Файл із некоректним форматом або файл не у форматі JSON відхиляється.

## Оцінювання

Метрика оцінювання для цієї задачі — **точність попарного впорядкування**. Вона перевіряє кожну пару фрагментів і ставить запитання: _який із двох має бути першим?_ Пара є правильною, якщо ваше передбачення дає таку саму відповідь, як еталонна розмітка. Для діалогу з `n` фрагментами існує $$M = n(n-1)/2$$ пар; нехай `I` — кількість інверсій, тобто пар, упорядкованих інакше, ніж в еталонній розмітці:

$$\text{score} = 1 - \frac{I}{M} \in [0, 1]$$

ℹ️ **Фінальна оцінка є середнім значенням оцінок окремих діалогів для всіх
діалогів у вибірці.**
